# Buscador GitHub

## Descrição
Este projeto é um buscador de repositórios no GitHub utilizando AJAX. Ele permite que os usuários pesquisem e visualizem informações sobre repositórios hospedados no GitHub.

## Tecnologias Utilizadas
- **JavaScript**: 35.5%
- **HTML**: 33.5%
- **CSS**: 31%

## Funcionalidades
- Pesquisa de repositórios por nome.
- Exibição de resultados com informações detalhadas sobre cada repositório.
- Interface amigável e responsiva.
